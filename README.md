# Signatures of selection

This repository contains a custom R script used to identify
potential signatures of selection in climate-associated candidate
genes based on nucleotide diversity (π), Tajima's D, and FST.

## Associated publication

Whole-genome duplication reshapes climate adaptation in
Arabidopsis arenosa. Molecular Biology and Evolution.

See the Methods section of the associated publication for
details of the analytical approach and selection criteria.
